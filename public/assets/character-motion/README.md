- `tree-chopping.glb`：UAL2 的 `TreeChopping_Loop`，29/30 秒。
- 动作 GLB 只保留对应动画及原骨架节点，195 条轨道/65 关节。移除其他动画、示范人网格/蒙皮/材质/纹理，保留的采样字节完全不变。
- `Male_Peasant.gltf/.bin`：源文件为四部分衣服/鞋/手部网格、5 个 primitive、12,894 三角；**不包含可见头部**。磁盘中的网格、绑定、权重、UV 和骨骼未改。JSON 只移除法线/ORM 贴图引用，设零金属/0.8 粗糙度。两张原始 basecolor 未缩放、未改像素；较大原 ZIP 未入仓。
