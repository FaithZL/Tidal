## 设计与边界

- 沿用 A09 暖色 2D 建议，原创 SVG 背景 + Phaser 分层绘制角色/物件。未取得产品最终视觉批准。sources/ 参考附件本机缺失，仅对照 SOURCES 中的文字说明；不截取参考游戏资产。
- ActionAnimator 只接收 GameEffect 与快照；阶段到达后保持，绝不自动补齐动作。只为粒子、倒树、木材飞行使用本地表现时钟。
- 摄像头/识别/领域/输入接口不修改。暂停冻结表现；epoch 变化清理未完成动作；reset/dispose 清理全部临时效果。库存、Carry 和休息位置均由权威快照派生。
- NPC 是显式标记的预设伙伴：第一段休息收拢现有木材并靠近推车，第二段整理场地/固定货物；不持有控制器写接口。
- 无 Git；.t04-baseline 保留进入本轮的源码、测试和文档，不创建虚构提交。

## 检查重点

- 效果在领域 subscribe 之前发出：场景先读取最新快照，再应用效果，不能在切换时遗漏最终倒树/装车。
- 暂停跨多个原因、恢复 epoch、旧局/旧任务回调与重复 impact 不能复活临时物件。
- Carry 画面必须只依赖有效时长，松开后不可缓动前进。
- 展示中的木材从权威库存借用，不叠加出第二份实体；NPC 无业务修改入口。
- 资源缺失、Scene shutdown 和新局不能残留订阅/动态 actor。
