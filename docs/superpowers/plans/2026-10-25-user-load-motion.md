# 用户人物装车动作实施计划

**Goal:** 修复NPR页用户人物装车抛木时仍为固定姿势的问题，补上下蹲抱木、站起举木、向车内抛送和收手回位。

**Approach:** 保留原静态适配器和独立人物样片。新增装车专用适配器，复用当前FBX派生17骨架和已测试的表现插值规则；装车工作时显示派生身体、隐藏斧头，其他阶段保留原静态造型。双掌实际世界中点接既有木头持有/飞行锚点，木头库存和提交仍只由SessionController写入。

**Constraints:** 不修改原FBX/UV/贴图、输入规则、负例、时限或计数门限；保留未提交工作和历史QA；不commit/push/部署。当前用户明确授权装车动作，未授权自动接入完整砍树/行走动画。

- [x] 真实浏览器/失败测试复现静态手锚点，保存当前表现。
- [x] 真实FBX失败单测后实现UserLoadCharacter/UserLoadMotion：肢长约束、脚底支撑、实际掌心锚点、有限观察delta、暂停/失效冻结与显式复位、异步取消和一次释放。
- [x] FarmWorld接入装车适配器，session/taskRun/sourceEpoch变化复位表现；更新明确的“装车局部动作、其余静态”状态标签及对应既有标识断言，不放宽业务断言。
- [x] 相关单测、类型/lint、模型/装车/NPR E2E、构建及素材校验，实际看生产动作逐帧/录像；历史NPR截图另存本轮后按SHA恢复。
- [x] 独立审查、更新PROGRESS、核对未提交工作；真实摄像头/最终美术等限制保持。
