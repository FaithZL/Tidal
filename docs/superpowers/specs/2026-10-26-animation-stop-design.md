# 手动随时停止与继续动画

用户明确选择“手动一键停止，可继续播放”。在现有项目增加常驻“停止动画 / 继续播放”及Shift+P快捷键，教学内提供同一功能入口；不实施摄像头自动停动判断，不提交/push/部署。

停止时角色、NPC、木材/车/特效和标准骨骼示范冻结，训练只通过SessionController现有user暂停停止计次/有效时间；合成准备预览和独立教学也冻结。摄像头视频与跟踪检查继续，供重新准备/判断失效；视角仍可手动旋转检查姿势。继续只解除此次停止新增的user暂停，保留原有user/tracking/source-error/visibility及已有成果；半次动作沿用sourceEpoch失效规则。

方案沿用既有训练暂停并给独立播放器加全局门禁；只停止渲染会让成果在背后继续，故不选。原暂停按钮/P保留兼容，全局停止时不能绕过门禁；点击停止后保持状态，直到明确继续。资源未就绪前可停止，禁止背后默认开局，明确继续后沿用原默认开局条件；重置不自动解除停止。停止状态不写入保存的模拟偏好。

所有播放器切换停止/继续即时清时间基准，不补短空档。教学保持原先播放/定格选择，全局停止期间本地播放/重播不可绕过；切步骤允许静态查看。教学打开本来就暂停训练，因此不能把普通训练user暂停误当教学停止。新增按钮须在桌面/窄屏及教学模态可触达，标签/pressed状态一致。
