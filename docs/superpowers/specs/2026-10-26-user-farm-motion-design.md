# 用户人物挥砍与行走动作补全

用户于2026-10-26明确选择“补现有挥砍和行走动作”，沿用已批准的3D农场流程及动作阶段契约。这里的“锄地”指现有砍树时挥工具，不新增任务、器械或识别动作。实现细节由本轮选择，最终美术仍需用户看动画确认。

## 目标与约束

- 在当前NPR用户FBX上显示准备、下挥、回收，以及walk/push/pull中的交替迈步和相应上肢姿态。
- 保留现有装车动作、第7版独立样片和旧prototype对照；使用同一17骨架、同一渲染器与原素材。
- 表现只读WorldActor/权威阶段，不能循环样片来模拟输入，不能修改识别、计次、库存、有效持姿时长或路径。
- 暂停/异常间隔冻结；显式session/task/epoch复位清半次；资源仍单一所有者，迟到加载取消可释放。
- 本机目录/main基线增量工作，保留全部未提交内容，不安装依赖、commit/push或部署。

## 接入选择

推荐并采用现有派生骨架：扩展UserLoadCharacter的可选farm范围，默认load范围保持原接口/断言；FarmWorld显式启用farm。挥砍复用UserCharacterMotion的实际握柄和原斧头几何，由阶段驱动有限区间并保持中途接续；移动从现有stride派生迈步，并用IK保持肢长和足底高度，推拉双掌固定在现有车把世界位置。局部木桩落点须适配当前树干摆位；退出挥砍恢复握指几何后再进入装车。

其他方案：直接自由循环第7版样片会脱离动作阶段；新增外部动作模型/骨架会引入重定向、许可和素材变更，均不适合本次补齐已有动作的范围。

## 验收

真实FBX的身体与斧头运动，双手与握柄接触、落点贴近树干、足底不穿地、肢长保持；walk/push/pull都有交替步，推拉手锚与车把匹配。中途换阶段、暂停/恢复、复位和异常间隔保留负例；挥砍→行走→装车不污染派生几何，原源网格/UV/材质不变。浏览器验证真实手/脚/刀尖变化及整局15份木材守恒；正常速度生产构建实际查看，记录限制，不以合成输入宣称真人识别准确率或性能达标。
