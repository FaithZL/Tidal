# 城堡柔和卡通贴图

用户选择柔和卡通石堡：浅灰暖色石墙、深色木门窗、山岩少量苔藓，与现有田园场景协调。原FBX、几何、UV、许可与全部未提交工作保留，不提交/推送/部署。

采用新生成的本地颜色素材，离线投射并烘焙到原UV图集；运行时只增加一张颜色贴图，沿用Soft Toon与既有异步加载/释放。不是恢复原作者贴图，不宣称PBR。山岩与建筑连在同一网格，区域遮罩为本轮人工近似，应实际审阅正反面和窄屏。

比较：直接沿碎片UV重复铺砖会破坏方向比例；运行时三平面映射增加采样与着色成本。因此选择离线烘焙的UV图集，保留生成素材、烘焙工具和来源SHA，可单独替换。

验收：实际灰模变为有石纹/木门/山岩颜色的城堡；原件SHA和6万三角保持，贴图加载失败显式报错，资源一次释放，普通/NPR场景和城堡近景均可见，无外源或摄像头申请。范围验证类型/lint、相关单测/E2E、构建/素材校验及生产截图；上一轮prototype暂停截图失败仍为已知未解决问题，不自动扩展修复。
