# Tidal 本地路演操作手册

适用分支：`feature/t07-t11-completion`。这是一套有明确模拟标签的农场运动概念 Demo；当前交付证据见 `TEST_REPORT.md`。用户目前没有摄像头，不能用自动演示替代真人验收。

## 启动

Windows / Node 24.14.0 / npm 11.9.0；第一次安装需要网络，运行所需资源随后均在本地。

```powershell
npm ci
npm run assets:sync
npm run assets:verify
npm run build
npm run preview -- --port 4175 --strictPort
```

打开 `http://127.0.0.1:4175/`。保持终端运行。更新代码后重新 build；修改源码用 `npm run dev`。安装前先结束本项目旧 Vite 服务，避免 Windows 文件占用。摄像头需 localhost 或 HTTPS；不直接打开 HTML 文件。不需要账号、后端或外网 API。

## 无摄像头演示

1. 接受首页的预设计划。
2. 打开“无摄像头测试”，看到明确标注的合成骨架。
3. 点击“开始自动模拟演示”。5秒准备后依次完成砍树、休息、装车、休息、拉车、结算，约两分半。
4. 可随时暂停。关闭测试会暂停，点继续后改为键盘：Space 完成一次动作，拉车长按 Space。
5. 结算展示15单位到家木材、100游戏金币、100游戏体力和固定T恤；没有真实心率/卡路里。返回首页重置，测试开关自动关闭。

建议讲解：“这是无摄像头的脚本演示，合成骨架展示交互效果，结果是游戏演示数据；摄像头识别需另行标定和真机验证。”

音效默认关闭，点击顶栏“开启音效”后启用原创短反馈音，再点击即可静音。浏览器音频不可用时继续无声演示，不影响计数。自动测试验证了 Web Audio 控制和释放，实际扬声器听感仍需现场检查。

## 有摄像头后

选择桌面 Chrome/Edge，固定机位、单人、光照稳定、全身和举手范围入镜。保持舒适幅度，调试使用空载动作；不要为了触发阈值加重、加快或强行加深动作。

1. 关闭模拟开关，进入准备页，点击“开启摄像头诊断”，允许视频权限。
2. 等待本地模型与 WASM 初始化；确认实时视频、骨架与本人运动对应。仅返回推理帧数并不等于识别真人成功。
3. 展开标定，选择本人主手。自然站立2秒；按提示采集挥砍两姿态和装车四姿态，各0.6秒；持姿/放下各2秒。
4. 所有任务标定就绪后，手动点击摄像头训练入口。只在完整动作复位后计次，持姿需持续确认后才计有效样本。
5. 分别检查停顿、放下、遮挡、离镜、失焦、暂停与恢复。丢跟踪后重新标定并显式恢复；已有用户/后台暂停仍需解除。
6. 休息不会因离镜无限冻结；休息结束后等待重新准备，再完整倒计时。

人体姿态只能判断已标定的可区分姿态，不能确认真实持握、重量或身份。同姿态空手不会被可靠识别为放下；同位置换人/缓慢换位需手动重做标定。阶段同步并非逐关节复制。A04/A06 的接受仍须产品确认。

## 故障与退出

| 现象 | 操作 |
|---|---|
| 未找到摄像头 / 被占用 / 权限拒绝 | 连接设备、关闭占用程序或在浏览器站点设置允许视频后重试 |
| 初始化较慢 | 10秒提示，可停止/取消；30秒超时后重试 |
| 模型 / WASM 错误 | 停止，终端运行 `npm run assets:sync`、`npm run assets:verify`，重建并刷新 |
| 姿态不可区分 / 关键点不全 | 调整机位、保持全身可见后重做；不能通过加大负重来解决 |
| 下蹲提示髋部差异不足 | 重采当前步骤，必要时重新标定站立基线；仅屈膝、髋部不下降不会通过。调整机位，不要强行加深动作 |
| 训练失去跟踪 | 保留已提交成果，重新完成标定并手动恢复；不拼接半次动作 |
| 需要改键盘 | 明确点击“切换键盘”或“关闭摄像头并切换键盘”，然后点击继续；结算保留混合来源 |
| 切到后台后回来 | 主动点击继续；若摄像头标定失效先重新准备，不补计离开时间 |
| 结束本局 | Esc 后确认，或“重新开始”；返回首页、清零、释放摄像头/Worker |

失败讲解：“本次摄像头条件还未通过验证，现在明确切换到键盘/自动模拟展示游戏流程。”不要把备用模式说成真实识别。
