# 用户蓝衣人物：绑定与局部动作只读审阅

日期：2026-10-22。范围：现有源码、真实用户 FBX 的 CPU 拓扑审计与上一轮真实浏览器静帧；本审阅没有修改应用源码、运行 GPU/E2E、上传模型、安装依赖或写入 Git。以下为实现建议与待验证断言，不是动画已经通过的声明。

- `src/game/world/characterSampleClock.ts`、`sampleCharacter.ts`、`tests/unit/{characterSampleClock,sampleCharacter,sampleMotionContinuity}.test.ts` 与 `tests/e2e/character-motion.spec.ts` 已读。原样片的暂停、绝对采样、边界连续性、左右手接触、鞋底落地、负例、释放契约有效，应保留，不要为了新角色替换而弱化旧用例。

## 新绑定的最小接口

与绑定代理已确认建议接口：

```ts
createUserCharacterRig(model) -> {
  root, motionSupport: 'derived-skeleton', mesh, skeleton,
  bones, rest,
  axe: { root, mesh, grips: { lower, upper }, blade },
  resetPose(), dispose()
}
```

关节名为 pelvis/spine/chest/neck/head、左右 upperArm/foreArm/hand、thigh/shin/foot；新骨骼局部 +Y 指向下一节，归一化人物面朝 +Z。rest 应记录原固定砍姿中的局部/世界位置与旋转，用逆绑定矩阵精确保持源网格。斧根独立挂 rig.root，不同时挂手和再施加一套跟随，防止双重变换。

绑定代理随后核实：`rig.root===model.root`；源 mesh 在原 owner 下隐藏而不丢弃，以便原 owner 释放原资源，rig 释放派生几何/skeleton 后调用幂等 model.dispose。viewer 应先在原点建立 rig/motion，再将 root 放到场景；不要把场景平移当新骨架的 rest 坐标。实际源姿态仅左手（+X）握斧，右手（-X）在前膝附近自然下垂；不能声称原双手已接触，也不应仅把右手当前点投影到柄上而造成伸长。手骨位于 wrist，当前真实代码将 palm offset 暴露为 `rig.palms.left/right`（以对应手骨局部绑定坐标保存），不是旧 `.065` 常数。

**不得套用的旧值：** CC0 的 pelvis 骨高、骨长、`Head` 挂点 `-.065`、头部 `.84/.86/.86` 缩放、手掌 `(0,.065,0)`、0.3 单位双手间距、旧斧 `.95` 长度，以及旧 upperarm/foot 名称。新值必须来自本次网格的解剖标记和源斧轴，不可用相似外观替代测量。

## 推荐的自然动作构造

1. **固定姿态是绑定姿态，不是待机。** 首先验证 resetPose 的蒙皮顶点逐点重建原人物。再从髋/腰向上展开成略微屈膝的站立，不要只将整个模型绕脚根向后旋转。把站立、预备、低位受力、回收看作同一新骨架上的目标姿态；以绝对时间采样，不累加每帧旋转。
2. **脚先确定、髋再运动。** 从真实左右鞋底分别建立支点/足底方向；原来源两脚可能不完全共面，不要只拿全体最低点推断两脚。让左右脚独立接触 y=0，记录这两个站位。髋/腰做少量上下、前后及扭转，双腿 IK 在自身骨长内补偿，鞋底方向保持地面。不要照搬旧 `groundFeet()` 的“整体 Y 减最小值”便声称双脚锁住；该方法只能阻止一个最低点穿地，不能限制水平滑移或另一脚悬空。
3. **髋/腰主导，头和肩做小幅反向平衡。** 准备时髋略后移、胸略开、抬手带起斧；下挥时髋前送、胸沿斧向前俯，膝部缓冲；撞击后先保留低位，头颈随后回正。不要用大幅头点动和整体摆动制造“自然”。新头颈已与源网格一体绑定，无需再附加原程序头。
4. **斧作主约束，两手解算到真实柄。** 用原斧轴/实测上下握点构造刚体轨迹，再以新手掌局部 offset 求腕目标。双手位置由同一刚性柄提供，手腕方向来自柄轴和掌面，而非把两腕简单拉到同一个点。双臂用各自上臂/前臂长度解析 IK，肘 pole 在胸外/前侧连续变化；不能突然在 blend>0 时换 pole。若源手本来没包住柄，可修正掌心中心接触，但不能把掌心贴柄称为完整手指包握。
5. **上举轨迹绕开脸和胸口。** 从低位持斧先收至身前，再抬向右肩上方，手肘外展有限；柄和斧刃别直线穿过头/面。下挥沿清晰弧线落向固定木桩，肩-肘-腕的目标必须可达，不能靠拉长胳膊到达。新蓝衣比例更短壮，先减幅度而不是套旧高举姿态。
6. **回收不是下一次上举。** 受力后保持低位卸力，再将斧柄收回身前的低位站立。双手可继续握住原斧；不必为模仿旧 CC0 待机而硬让副手突然放开。回收末与下一轮待机姿态位置、旋转及速度都接上。
7. **呼吸有界且不破坏接触。** 站立仅胸部/肩部小幅呼吸、重心数厘米以内，双脚固定；两手仍由持斧目标解算。不能直接把呼吸正弦叠到整个 root 上，不让斧和手分离。

## 保留的阶段节奏

优先沿用现有可审阅 7.1 秒时钟，以免影响旧 prototype 用例与 UI：

| 时间 | 阶段 | 新人物表现建议 |
|---|---|---|
| 0–2.4、5.6–7.1 | idle | 屈膝自然站立、低位安全持斧、胸肩轻呼吸 |
| 2.4–3.35 | prepare | 五次平滑抬斧；髋后移，臂/肩逐渐展开 |
| 3.35–3.65 | prepare | 稍作蓄力，避免完全机械僵停 |
| 3.65–4.15 | strike | 一次明显下挥，峰速居中；不重复上举 |
| 4.15–4.40 | recover | 低位受力缓冲，腰/膝吸收，柄仍刚性 |
| 4.40–5.60 | recover | 单向卸力、回到低位站立，不再抬到头顶 |

五次平滑能避免位置/速度在段末硬切，但多个关节同时同曲线会显得机械。可在连续边界前提下给髋/胸/手约 30–80ms 的相位错开；这是建议初值，不是用户确认或动捕事实。若使用现有 `CharacterSampleClock` 的 `chopTime/weight`，将它映射到新角色自己的 pose 曲线即可，不要将 CC0 动画 track 直接赋给这些骨骼。

## 优先补的失败测试/可验断言

先让新角色接入、姿态变化、脚锁与握持的用例真实 RED，再实现；不要把旧角色已有通过项当作新角色验收。

- **源重建与资产保持：** resetPose 所有蒙皮顶点与源归一化坐标匹配；分离斧仍 230 三角、整体总三角不丢；原 UV/map 引用不变；skin index 有效、最多 4 影响、非负且和约 1；所有法线/矩阵有限。负例用缺失关节点、NaN/错误权重触发拒绝。
- **真实运动，而非 root 晃动：** 站立与挥砍的 head/chest/hand 相对 pelvis 有实质差异，蒙皮顶点随相应骨变化；caller root 的 x/y/z/yaw 保持不变。新骨架自有的手肘/膝方向测试，不能只 assert 骨骼数量>0。
- **双手与刚斧：** 在准备、下挥、低位缓冲、回收密采样两掌到各自真实握点距离。按模型尺度建议先以 2–3cm 为工程目标，超出要显示原因并改姿势/IK，不以宽松阈值掩盖；双握点间距及刀刃到握点刚性长度不变。用禁用一侧 IK 或错置握点的输入作为负例。
- **脚底：** 在全循环和阶段边界，分别测左右真实蒙皮鞋底的最低点/多个底面探针；不穿地、不出现明显悬空；左右鞋跟/脚尖相对 caller root 的 XZ 漂移建议目标 <1cm。原 source 两脚若需重平面，另保留“原绑定姿态重建”测试，不混为同一断言。负例禁用腿 IK 或只做整体 Y 校正时应发现滑移/悬空。
- **连续性：** 保留旧七个边界 2.4/3.35/3.65/4.15/4.4/5.6/7.1，新角色再测 wrists/palms/elbows/blade/head/feet；在 ±1e-5s 跨边界位移应趋近 0，并检查附近有限差分速度，防止位置连续但加速度突变。保持旧“impact 立即切 idle”负例；为新角色增加同类负例。
- **持姿/暂停/确定性：** 相同绝对时间重复采样不漂移；A→B→A 逐骨/逐顶点还原；暂停、后台、异常或 >100ms 间隔不补时。暂停切 idle、重播或拖时间轴立即重画，旋转镜头不推进动作；真实截图像素冻结仍有效。
- **资源/失败：** 新 skeleton/派生几何/材质与原模型资源各一次释放；重复 dispose 无重复事件；加载迟到、context lost/页面关闭后不能挂回舞台或自动恢复。用户模型加载失败显式报错，不能静默显示 prototype。
- **模拟偏好：** 样片浏览/重播/暂停不读写既有 `tidal.demo.enabled`；回到局部农场仍保留默认模拟/显式真实摄像头规则。原输入/领域完整流程回归继续存在，但不要求把局部动画完成事件接成计数。

## 实拍审阅重点与边界

至少保留正面、左右 3/4、背面与低位角度，四个可见暂停时间点 0.8/3.4/3.95/4.95 秒。实录一整循环+回到 idle，逐帧查：脚底/地影贴合、肩袖是否压扁或拉尖、胯部是否塌陷、斧刃是否穿头/躯干、两掌是否滑柄、回收是否反向多抬一次。静帧通过不能替代连续动作审阅。

绑定来自人工解剖标记与派生蒙皮，不是原作者提供的专业绑定或动捕。4900 三角的合并低模与原手形会限制极端举臂/指节细节；局部样片先控制可接受动作幅度，明显变形要修权重或关节点，不扩全农场。摄像头、真实手机、硬件 GPU 与最终动作自然度仍按实际证据标记；本审阅没有替这些项目验收。
